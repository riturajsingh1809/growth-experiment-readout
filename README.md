# Growth Experiment Readout

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes a growth experiment by comparing Control and Treatment groups and evaluating whether the treatment should be shipped.

The analysis focuses on conversion performance, experiment effect, statistical significance, confidence intervals, Sample Ratio Mismatch (SRM), guardrail metrics, segment performance, and business recommendations.

## Project Workflow

*Excel → Google Colab → Python → Tableau → GitHub*

* Data cleaning was performed in *Microsoft Excel*.
* The cleaned dataset was analyzed in *Python using Google Colab*.
* Statistical and business analysis was performed using *Pandas, NumPy, and SciPy*.
* The final experiment insights were visualized in *Tableau*.
* The project files and documentation are maintained in *GitHub*.

## Key Analysis

The project evaluates:

* Control vs Treatment performance
* Primary conversion rate
* Absolute and relative effect
* 95% Confidence Interval
* P-value and statistical significance
* Sample Ratio Mismatch (SRM)
* Guardrail metrics
* Regional performance
* Skill-level performance
* Experience-level performance
* Monthly experiment trends
* Final experiment verdict
* Business recommendation
* Experiment learning log

## Key Business Question

*Does the Treatment provide enough evidence of a positive improvement without negatively affecting important guardrail metrics?*

## Outcome

The analysis provides an evidence-based *SHIP, NO-SHIP, or INCONCLUSIVE* recommendation instead of making a decision only from the observed conversion rate.

## Note

This project uses a sample dataset for portfolio/practice analysis. The experiment fields and statistical results should not be presented as live production experiment results.
